Sources & methods

Everything shown in the lab is computed in the browser from the matrices described here. Nothing is uploaded. The analysis engine (JavaScript) is part of the site, and the R scripts that build the matrices are in the project repository, so every number can be traced.

Human: lung adenocarcinoma (CPTAC)

  • Li Y, Dou Y, et al. Proteogenomic data and resources for pan-cancer analysis. Cancer Cell 41, 1397–1406 (2023). doi:10.1016/j.ccell.2023.06.009
  • Gillette MA, Satpathy S, Cao S, et al. Proteogenomic characterization reveals therapeutic vulnerabilities in lung adenocarcinoma. Cell 182, 200–225 (2020). doi:10.1016/j.cell.2020.06.013

Files: harmonized data freeze v1.2, LUAD folder (LUAD_RNAseq_gene_RSEM_coding_UQ_1500_log2_{Tumor,Normal}.txt, LUAD_proteomics_gene_abundance_log2_reference_intensity_normalized_{Tumor,Normal}.txt, LUAD_phospho_site_abundance_log2_reference_intensity_normalized_{Tumor,Normal}.txt, LUAD_meta.txt), from the public CPTAC pan-cancer bucket listed at kb.linkedomics.org/download.

Processing

  • 101 patients with a tumour and a normal-adjacent sample in all three layers (202 samples).
  • Ensembl IDs mapped to HGNC symbols with org.Hs.eg.db; RNA restricted to protein-coding genes expressed in ≥ 90% of samples (median log₂ ≥ 4). Phosphosites labelled “SYMBOL site”.
  • Teaching pools: features with ≤ 50% missing values, ranked by variance across all samples without labels; the top 1,500 per layer are shipped. No imputation before shipping.
  • RNA–protein concordance computed offline on all 11,299 genes measured in both layers (Spearman, ≥ 20 paired observations).
  • Gene sets: MSigDB Hallmark, GO biological process and Reactome via msigdbr 26.1.0, restricted to genes present in the data (5–400 members).

Honey bee: nurse bees at highbush blueberry apiaries

  • Zhong H, Shi Y, Rogalski JC, et al., Zayed A, Foster LJ. Omics insights into the effects of highbush blueberry and cranberry crop agroecosystems on honey bee health and physiology. Proteomics (2025). doi:10.1002/pmic.70033

Files: MassIVE MSV000097590 (ProteomeXchange PXD062819), search/SEARCH/Results_HBB_2020/diann-output.pg_matrix.tsv, Results_HBB_2021/t2t4_2021_ProteinGroups.tsv and the search database Bee_plus_virus_nosema.fasta.

Processing

  • Run names parsed as apiary (HBB01–10), colony set (e/u), timepoint (t2/t4) and tissue (H head, A abdomen, G midgut). All 40 pools have all three tissues. Each pool contains 12 nurse bees.
  • The 2020 and 2021 matrices are separate DIA-NN searches; they were joined by protein group and log₂-transformed. Year is therefore also the mass-spectrometry batch. The lab offers an optional within-year centring of each protein.
  • Protein groups were assigned to honey bee, Nosema or virus with the search FASTA. Pathogen protein signal = log₂(1 + summed intensity) per pool (gut for Nosema, all tissues for viruses).
  • Each tissue view keeps honey bee protein groups with ≤ 50% missing values in that tissue, top 1,500 by variance (label-free).
  • Labels: UniProt gene names where informative, otherwise the RefSeq description. GO biological process terms from UniProtKB entries cross-referenced to each RefSeq protein (mostly electronic), propagated to ancestors with GO.db.
  • The public deposit holds more runs than the 60 analysed in the paper; the meaning of the colony-set codes (e/u) is not stated in the article and is used here only as a label.

Analysis engine

Single-layer statistics

Per-feature linear models on observed values with empirical-Bayes variance moderation following limma (fitFDist, legacy equal-df estimator). Paired designs are tested on within-pair differences, which is equivalent to ~ pair + group. Benjamini–Hochberg FDR within each layer. Welch tests are shown for comparison. Checked against limma 3.x on simulated data: identical coefficients; moderated t within 0.003.

PCA

Centred model matrix (scaled as chosen), missing entries filled with the feature median or minimum for PCA only; top components by subspace iteration with Rayleigh–Ritz (identical to a full eigendecomposition to 10⁻⁶).

Multi-view factor model

Bayesian group factor analysis with variational inference: Gaussian likelihood with a noise precision per feature, Gaussian factors, and automatic relevance determination (Gamma priors) on the weights of each factor in each layer. This is the Gaussian MOFA model without the spike-and-slab sparsity prior. Missing values are skipped in the likelihood. Initialised by block-weighted joint PCA; convergence when the relative change in factor scores falls below 3 × 10⁻⁴. Variance explained follows the MOFA2 definition on observed entries. On simulated three-view data the factor scores matched MOFA2 1.20 (R, spike-and-slab off) with |r| ≥ 0.9995 and per-factor R² within 0.3 percentage points.

Other analyses

  • Factor–covariate association: one-way ANOVA (η²) for categories, Spearman ρ for numbers.
  • Layer agreement: Spearman correlation between sample-distance matrices (Mantel statistic).
  • Variance partition: type-II sums of squares per covariate, or a balanced two-way decomposition on complete pairs for paired designs.
  • Enrichment: hypergeometric over-representation against the scored background, and a Mann–Whitney rank test (AUC effect size), both BH-adjusted.
  • Prediction: ridge-penalised logistic regression on the top |t| features chosen inside each training fold; stratified five-fold cross-validation repeated five times. The leaky variant selects features on all samples first.

Figures

All charts are SVG drawn in print units (1 unit = 1 pt) at journal column widths of 89, 120 or 183 mm, with 6–7 pt Helvetica/Arial text and 0.6 pt axes. Group colours follow the Okabe–Ito colour-blind-safe palette; layer colours were checked for colour-vision deficiency and contrast. Downloads keep the physical size (SVG in mm; PNG at 600 dpi).
